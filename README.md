# Dueloro — Marketing Site

Public landing page for Dueloro: a flat, brutalist terminal page with one aperture of depth — the recolored ShaderGradient behind the hero and again in the closing CTA window.

## Stack

- React 19 + TypeScript + Vite
- `@shadergradient/react` + `@react-three/fiber` + `three` (code-split, lazy-mounted)
- Plain CSS mapped to the app's design tokens

## Run

```bash
npm install
npm run dev
npm run build
npm run preview
```
